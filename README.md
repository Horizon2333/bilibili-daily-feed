# B站动态按天看

> 按日期整理关注动态。少一点反复刷新，多一点从容。

![B站动态按天看宣传图](./assets/store/promo-1400x560.png)

如果你习惯把关注账号的每一条动态都看完，但因为忙碌已经落后了几十天，B 站默认的信息流会让你不断向下翻页，而且很难确认某一天是不是已经全部看完。

这个扩展解决的就是这件事：**选定日期，它会自动读取到前一天，把当天的图文和视频集中列出来。** 看完以后结果继续保存在本机，下次不用从最新动态重新翻起。

> 本扩展是社区维护的非官方第三方工具，与哔哩哔哩官方不存在隶属、授权、合作或背书关系。

![扩展在 B 站动态首页中的实际界面效果，内容为脱敏示例](./assets/store/screenshot-real-effect.png)

## 它能帮你做什么

### 1. 不再疯狂刷新

选择想看的日期，点击“加载这一天”。扩展会一直读取到前一天，确保目标日期末尾的动态也被收集，而不是看到日期刚出现就提前停止。

### 2. 一眼分清图文和视频

结果集中展示作者、头像、发布时间、标题、正文摘要、配图或视频封面，并保留原动态和视频链接；点击 UP 主头像或昵称可打开其个人主页。视频会额外显示时长；充电专属视频会在标题旁醒目标记，合集更新也会正确显示标题、封面和“合集”标记。视频封面右上角提供“稍后再看”按钮，并会同步当前账号中是否已经加入；再次点击蓝色勾选即可移除。

结果支持从早到晚或从晚到早排列；多图动态会显示图片总数。内容过滤菜单会同时显示当天的全部、视频、图文和其他数量，四类均可直接筛选。

### 3. 下次接着看

已经读取的动态会缓存在浏览器本机。你可以查看缓存覆盖的日期、条数和空间，也可以只清除某一天。扩展会按账号记住最后选择的日期，下次打开时从原来的日期继续。

### 4. 多账号不会串记录

缓存按照当前 B 站 UID 隔离。切换账号后会自动切换到对应记录，多个动态页同时加载也会自动合并结果。

## 5 分钟安装

目前扩展通过 GitHub 发布，需要使用浏览器的“开发者模式”安装。

1. 打开 [最新版本页面](https://github.com/Horizon2333/bilibili-daily-feed/releases/latest)。
2. 在页面底部的 **Assets** 中下载名称类似 `bilibili-daily-feed-vX.Y.Z.zip` 的文件。
3. 解压 ZIP。请记住解压后的文件夹位置，不要直接选择 ZIP 文件。
4. 打开扩展管理页：
   - Chrome：在地址栏输入 `chrome://extensions`
   - Edge：在地址栏输入 `edge://extensions`
5. 开启页面右上角或左侧的“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择刚才解压出的文件夹。
7. 登录 B 站并打开 [动态首页](https://t.bilibili.com/)，页面右侧会出现“B站动态按天看”。

安装完成后，请保留解压出的文件夹；浏览器仍需要从这个文件夹加载扩展。

## 第一次怎么用

假设你已经追到 34 天前：

1. 在面板中选择你准备继续观看的日期。
2. 内容选择“全部动态”，或只看“视频”。
3. 点击“加载这一天”。
4. 等待提示“已越过目标日期”。这代表扩展已经读取到前一天，目标日期应当收集完整。
5. 从面板中的结果逐条打开原动态；下次打开同一日期时可以直接查看本地缓存。
6. 使用日期两侧的按钮或 `Alt + ←/→` 切换到相邻日期，继续向今天追赶。

正常情况下扩展会直接分页读取，不需要你手动翻页。只有接口临时不可用时，才会使用页面自动滚动作为后备方案。

## 常见问题

### 它会点赞、评论或修改我的账号吗？

默认不会。扩展不会点赞、投币、收藏、转发、评论、关注或发布内容。扩展会只读查询稍后再看列表以显示按钮状态；只有当你主动点击某个视频的“稍后再看”按钮时，才会加入或移除当前 B 站账号的稍后再看记录。

### 为什么加载某一天时还要读到前一天？

B 站动态采用分页加载。如果刚看到目标日期就停止，最后一页中仍可能还有同一天的动态。越过到前一天后，才能更可靠地确认目标日期已经收齐。

### 缓存保存在哪里？

缓存在当前浏览器的 `chrome.storage.local` 中，不会上传到开发者服务器。默认最多保留每账号最近 90 天、5,000 条动态，以及最近使用的 5 个账号，总缓存约 8 MB。

### 切换 B 站账号会混在一起吗？

不会。扩展会先确认当前登录 UID，再读取该账号自己的缓存。账号接口失败或尚未登录时，面板会分别提示并提供重试按钮。

### 如何更新？

面板会显示当前版本并自动检查 GitHub 最新正式版。发现新版时，标题栏会显示最新版本号和“下载更新”按钮；下载 ZIP 后解压并覆盖原文件夹，再在扩展管理页点击“重新加载”即可。更新前不需要清除缓存。

### 为什么有些动态仍然找不到？

被删除、仅特定用户可见、未由 B 站信息流下发的动态无法收集。B 站接口或页面结构调整后，也可能需要等待扩展适配。
