# B站动态按天看

一个本地 Chrome / Edge 扩展，在 B 站动态首页加入按日期加载面板。

> 本扩展是由社区维护的第三方工具，与哔哩哔哩官方不存在隶属、授权、合作或背书关系。

版本更新记录请查看 [CHANGELOG.md](./CHANGELOG.md)，数据处理说明请查看 [PRIVACY.md](./PRIVACY.md)。

扩展图标、商店截图与宣传图位于 [`assets`](./assets)，可直接使用的商店介绍见 [STORE_LISTING.md](./STORE_LISTING.md)。

## 功能

- 选择某一天，自动向下加载到前一天，确保目标日期的动态已全部进入列表。
- 查看当天全部动态，或只看视频投稿。
- 结果只展示标题、配图和原链接，避免重复显示大段正文。
- 把已经扫描的结果保存在浏览器本机，之后无需重新滚动。
- 使用当前登录 UID 隔离缓存，直接切换 B 站账号也不会混用记录。
- 自动清理超期和超量缓存：默认保留 90 天、每账号 5,000 条、最近 5 个账号，总缓存约 8 MB。
- 多个动态首页标签页的缓存写入由扩展后台排队合并，避免互相覆盖。
- 缓存管理可查看条数、日期范围、估算空间和最近治理时间，并可清除所选日期或当前账号全部缓存。
- 登录状态与账号接口错误会分别提示，并提供“重新确认账号”入口。
- 所有可点击链接仅接受 HTTPS 和受信任的 B 站资源域名。
- 每条结果保留作者名称与头像、发布时间、标题、适量正文、配图、动态链接和视频/内容链接。
- 监听 B 站分批插入的卡片，连续出现图文动态与视频时也会逐条采集。
- 卡片异步补全时会更新已有记录，不会因先读到空壳而漏掉最终内容。
- 标题只从动态正文区域提取，不读取底部评论区。
- 支持没有动态 ID 和详情链接的纯图文 Opus 卡片，并使用正文指纹稳定去重。
- 优先使用 B 站动态页的只读数据接口，直接取得每条动态的唯一 ID、发布时间，并生成标准 `/opus/<动态ID>` 详情链接；页面扫描仅作为后备方案。
- 接口请求由扩展后台发起，可复用 B 站登录态，并绕开内容脚本的跨域限制。
- 解析 Opus 的富文本节点；没有正式标题时使用正文首段，并保留最多 320 字摘要。
- 对接口中的动态模块增加递归文本兜底；只要存在正文，就不会显示“无标题动态”。
- 请求与 B 站动态页一致的 Opus 功能字段，并过滤 `MAJOR_TYPE_*` 等接口枚举元数据。
- 若接口临时不可用且页面卡片本身没有链接，会提供“定位原动态”并在页面中高亮该卡片。
- 拖动标题栏可移动面板，右下角可调整宽高；位置和尺寸都会自动保存。
- 仅在 `https://t.bilibili.com/` 动态首页运行；进入单条动态详情时不会创建面板或重新加载。
- 可随时停止自动加载或清空缓存。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `bilibili-daily-feed`。
5. 登录 B 站并打开 <https://t.bilibili.com/>，右侧会出现“B站动态按天看”。

## 使用建议

第一次追溯 34 天前的内容时，选择目标日期并点击“加载这一天”。扩展会优先通过 B 站接口分页读取，无需手动翻页；接口不可用时才会自动滚动页面作为后备。加载完成后结果会缓存在本机；以后每天打开一次并加载当天内容，就不需要再次追溯整段信息流。

## 隐私与限制

- 浏览器会为 B 站官方接口请求自动附带当前登录会话；扩展不会读取、保存或导出密码和 Cookie 内容。
- 动态缓存按当前登录 UID 隔离，数据只保存在浏览器的 `chrome.storage.local` 中，并受保留期限和容量限制。
- 扩展不会点赞、投币、收藏、转发、评论、关注或发布内容。
- 完整说明见 [隐私政策](./PRIVACY.md)。
- 本扩展为非官方第三方工具，不代表哔哩哔哩官方立场。
- B 站页面结构变化后，卡片识别规则可能需要更新。
- 被删除、仅特定用户可见或未由 B 站信息流下发的动态无法收集。
